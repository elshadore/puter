# 🖥️ Portable Puter 🖥️
The is essentially my *.dotfiles* repo. It is a complete mess and filled with legacy junk. The only thing of *actual* value is my [emacs](./dotfiles/.emacs.d/) config. Everything is a trash heap of fire 🔥🔥🔥.

Run the following command to initialize.
```sh
./puter/scriptz/puter-linkup
```

Once initialized you can also run the following in emacs.
```elisp
(puter/linkup)
```
